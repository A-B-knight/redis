### 1. Redis 数据类型的使用

#### 字符串 (String)
- **用途**: 存储会话数据
- **特点**: 支持过期时间（TTL）
- **代码位置**: `models.py` - `Session.create()`

```python
redis_client.set(session_key, json.dumps(session_data), ex=3600)
```

#### 哈希 (Hash)
- **用途**: 存储用户信息和任务详情
- **优点**: 可以部分更新，节省内存
- **代码位置**: `models.py` - `User.create()`, `Task.create()`

```python
redis_client.hset(user_key, mapping=user_data)
user_info = redis_client.hgetall(user_key)
```

#### 有序集合 (Sorted Set)
- **用途**: 
  - 任务列表（按创建时间排序）
  - 排行榜（按完成数排序）
- **优点**: 自动排序，支持范围查询
- **代码位置**: `models.py` - `Task.list_by_user()`, `Leaderboard`

```python
# 添加并排序
redis_client.zadd(f'user:{username}:tasks', {task_id: timestamp})
# 获取排序后的列表
task_ids = redis_client.zrevrange(tasks_key, 0, -1)
```

#### 集合 (Set)
- **用途**: 
  - 存储所有用户名
  - 存储所有任务ID
  - 存储用户的会话ID
- **优点**: 去重，支持集合运算
- **代码位置**: `models.py` - `User.create()`

```python
redis_client.sadd('users', username)
```

#### 发布订阅 (Pub/Sub)
- **用途**: 任务变更通知（预留功能）
- **代码位置**: `models.py` - `Task.create()`, `Task.update()`

```python
redis_client.publish(f'user:{username}:notifications', json.dumps(data))
```

## 📊 Redis 数据结构总览

```
user:{username}                    # Hash - 用户信息
users                              # Set - 所有用户名
session:{session_id}               # String - 会话数据（带过期）
user:{username}:sessions           # Set - 用户的所有会话
task:{task_id}                     # Hash - 任务详情
user:{username}:tasks              # Sorted Set - 用户任务列表
all_tasks                          # Set - 所有任务ID
leaderboard:completed_tasks        # Sorted Set - 排行榜
user:{username}:notifications      # Pub/Sub - 通知频道
```

## 💡 关键代码片段

### 1. 创建带过期的会话

```python
redis_client.set(
    session_key,
    json.dumps(session_data),
    ex=SESSION_EXPIRE_TIME  # 自动过期
)
```

### 2. 使用有序集合排序

```python
# 添加时指定分数（时间戳）
redis_client.zadd(f'user:{username}:tasks', {task_id: timestamp})

# 获取排序后的列表（降序）
task_ids = redis_client.zrevrange(tasks_key, 0, -1)
```

### 3. 排行榜实现

```python
# 更新分数
redis_client.zincrby('leaderboard:completed_tasks', 1, username)

# 获取排名（从0开始，所以+1）
rank = redis_client.zrevrank('leaderboard:completed_tasks', username) + 1

# 获取前N名
top_users = redis_client.zrevrange('leaderboard:completed_tasks', 0, n-1, withscores=True)
```

### 4. 批量操作（管道）

```python
pipe = redis_client.pipeline()
pipe.hset(key1, mapping=data1)
pipe.hset(key2, mapping=data2)
pipe.execute()  # 一次性执行
```

## 🐛 常见问题

### Q: Redis 连接失败？
A: 确保 Redis 服务器正在运行：
```bash
./src/redis-server
```

### Q: 如何查看 Redis 中的数据？
A: 使用 redis-cli：
```bash
./src/redis-cli
> KEYS *
> HGETALL user:your_username
```

### Q: 如何清空所有数据？
A: 在 redis-cli 中执行：
```bash
FLUSHDB
```
