# Redis 示例代码

这个目录包含 Redis 的学习示例代码。

## 文件说明

- `redis_examples.py`: 完整的 Redis 示例代码，演示各种数据类型和操作

## 运行示例

### 前置条件

1. **确保 Redis 服务器正在运行**

```bash
# 在项目根目录运行 Redis 服务器
cd /home/knight/code/redis
./src/redis-server
```

2. **安装 Python Redis 客户端**

```bash
pip install redis
```

### 运行示例代码

```bash
cd /home/knight/code/redis/examples
python3 redis_examples.py
```

## 示例内容

示例代码包含以下内容：

1. **连接测试** - 测试 Redis 连接
2. **字符串操作** - SET, GET, INCR 等
3. **哈希操作** - 存储和操作对象数据
4. **列表操作** - 实现消息队列
5. **集合操作** - 标签系统和集合运算
6. **有序集合操作** - 排行榜实现
7. **过期时间** - 会话管理和缓存过期
8. **管道操作** - 批量执行命令
9. **事务操作** - 原子性操作
10. **发布订阅** - 消息发布和订阅

## 学习建议

1. 先运行示例代码，观察输出结果
2. 修改代码，尝试不同的操作
3. 使用 `redis-cli` 手动执行命令，加深理解
4. 尝试实现自己的实际应用场景

## 常见问题

### 连接失败

如果遇到连接错误，请检查：
- Redis 服务器是否正在运行
- 端口是否正确（默认 6379）
- 防火墙设置

### 命令不存在

某些命令可能需要特定版本的 Redis。确保你使用的是 Redis 6.0+ 版本。
